# agency-poem-01 — "The Signature"

Entry for make.fun's **agency-poem-01** ("Write the best poem about agency").

`main.py` (Python 3.13, standard library only) writes one fixed poem to
`/output/entry.txt` (`MAKEFUN_OUTPUT_DIR` stands in for `/output` outside
the grader). Fully deterministic: the same bytes on every run, no network,
no input.

The poem is about agency as the right to speak — and sign — for oneself:
a woman who spent forty years signing another man's name finally writes
her own.
